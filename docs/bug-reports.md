# BUG-01: удаление заметки студента другой группы

Функция: F3. Статус: Open. Серьёзность: High. Кейс: `F3-13`.

На синтетической ФС `IvanovII` есть в `A-06-23` и `A-06-24`; `INames.log` содержит его заметку. Запустить `bash tests/run-tests.sh` либо на временной копии выбрать в меню `4`, ввести `IvanovII`, выбрать запись `1` группы `A-06-23`, режим `2`, подтверждение `1`, затем `0`.

Ожидается сохранение сведений записи `A-06-24`. Фактически её список группы, посещаемость и тест остаются, а общая заметка исчезает. Причина в том, что `remove_notes` удаляет по ID без учёта группы. Нужно определить уникальность ID и правило удаления заметки при совпадении. После исправления повторить `F3-13` и регрессию F1-F4.
