## BUG-02: удаление одной заметки портит остальные

Статус: Open. Серьёзность: High. Кейсы: `F3-11`, `F3-12` (FAIL). Окружение: WSL Ubuntu, Bash; тесты на временных копиях синтетической ФС.

Шаги: на копии данных выбрать `4`, ввести `SmirnovAA`, выбрать запись `1`, режим `1` (только заметка), подтвердить `1`. Затем выбрать `3`, найти `PetrovPA`, открыть заметки. Для полного удаления повторить с режимом `2`, затем открыть заметку `SmirnovBB`.

Ожидается: удалена только выбранная заметка или выбранный студент; заметки Петрова и второго Смирнова доступны, остальные файлы не меняются. Фактически: после удаления заметка Петрова не показывается, а `INames.log` изменён; после полного удаления не показывается заметка второго Смирнова. В обоих случаях меню сообщает об успешном удалении.

Вероятная причина: в `remove_notes` при переписывании файлов используется формат `printf '%s\\n'`. Он записывает буквальные символы `\n` вместо перевода строки, из-за чего парсер `show_note` больше не распознаёт записи. Нужно восстановить правильные разделители строк и повторить оба кейса вместе с регрессией F1-F4. Исходная ФС преподавателя не затрагивалась.
