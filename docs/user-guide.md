# Руководство пользователя

**Лабораторная работа № 4**\
**Программное решение:** консольное приложение для анализа данных
студентов\
**Версия:** релизная

## 1. Назначение программы

Программа предназначена для обработки файловой системы преподавателя,
подготовленной в рамках лабораторной работы № 3. Приложение позволяет
анализировать посещаемость и результаты тестирования, просматривать
досье студентов, удалять данные и формировать рейтинг успеваемости.

Приложение реализовано на Bash и запускается в терминале Linux.

## 2. Требования и размещение файлов

Для работы необходимы Linux или совместимая среда Bash, Bash и
стандартные утилиты Linux, используемые скриптом.

Файл `lab4.sh` и каталог `labfiles-3-26` должны находиться в одной
директории:

``` text
Рабочая директория/
├── lab4.sh
└── labfiles-3-26/
    └── ...
```

Программа определяет расположение каталога с данными относительно
собственного файла. Поэтому запускать её можно из любой текущей
директории терминала, если указан правильный путь к `lab4.sh`.

## 3. Запуск программы

Откройте терминал в рабочей директории и выполните:

``` bash
bash lab4.sh
```

При необходимости можно предварительно выдать файлу право на выполнение:

``` bash
chmod +x lab4.sh
./lab4.sh
```

Если обязательные каталоги исходных данных отсутствуют, программа
выведет сообщение об ошибке и завершит запуск.

## 4. Главное меню

После успешной проверки исходных данных отображается меню:

``` text
===== ЛР №4: АНАЛИЗ СТУДЕНТОВ =====
1. Лучшая посещаемость за период
2. Максимум правильных ответов
3. Найти досье
4. Удалить досье
5. Рейтинг успеваемости
0. Выход
```

Для выбора операции введите соответствующую цифру и нажмите Enter. После
выполнения операции программа возвращается в главное меню. Для
завершения работы выберите `0`.

## 5. Работа с функциями

### 5.1. F1 --- лучшая посещаемость за период

1.  Выберите пункт `1`.
2.  Введите начальный год периода.
3.  Введите конечный год периода.
4.  Выберите дисциплину:
    -   `1` --- «Цирковое дело»;
    -   `2` --- «Пересдачеведение»;
    -   `3` --- обе дисциплины.
5.  Введите номер группы, например `A-06-23`.

Расчётный год группы определяется по последним двум цифрам её
обозначения: к году поступления прибавляется три года. Если расчётный
год не входит в указанный период, программа сообщает об отсутствии
занятий за выбранный период.

Для каждого студента подсчитываются посещённые и все занятия по
выбранным дисциплинам. В результате выводятся студент или студенты с
наибольшей долей посещений, количество посещений, общее количество
занятий и процент посещаемости. При равном максимальном результате
выводятся все лидеры.

### 5.2. F2 --- максимум правильных ответов

1.  Выберите пункт `2`.
2.  Введите номер группы, например `A-06-23`.
3.  Выберите одну дисциплину или обе дисциплины.

Программа обрабатывает файлы результатов тестирования `TEST-*`,
суммирует количество правильных ответов по попыткам каждого студента и
определяет максимальный результат.

В выводе отображается максимальное количество правильных ответов и
список студентов, достигших этого результата. При равенстве результатов
выводятся все лидеры.

### 5.3. F3 --- просмотр досье

1.  Выберите пункт `3`.
2.  Введите фамилию студента латинскими буквами.
3.  Если найдено несколько совпадений, выберите нужную запись по номеру
    в списке.
4.  Выберите вариант просмотра:
    -   `1` --- только заметки преподавателя;
    -   `2` --- полное досье.

Полное досье содержит доступные сведения о посещаемости и результатах
тестирования по дисциплинам, а также заметки преподавателя.

### 5.4. F3 --- удаление досье

1.  Выберите пункт `4`.
2.  Найдите студента по фамилии и выберите нужную запись.
3.  Выберите режим:
    -   `1` --- удалить только заметки;
    -   `2` --- удалить студента из файлов группы, посещаемости и
        результатов тестирования.
4.  Подтвердите действие: `1` --- да, `2` --- нет.

Если удаление не подтверждено, данные не изменяются.

**Особенность заметок:** заметки хранятся в общей файловой области и не
разделены по группам. Если такой же идентификатор студента присутствует
в другой группе, программа сохраняет общую заметку, чтобы не удалить
сведения другого студента. Отдельно удалить такую общую заметку только
для одной группы невозможно из-за структуры исходных данных.

При полном удалении из выбранной группы удаляются соответствующие записи
этой группы. Записи студентов из других групп не затрагиваются.

### 5.5. F4 --- рейтинг успеваемости

1.  Выберите пункт `5`.
2.  Введите номер группы.
3.  Выберите одну дисциплину или обе дисциплины.

Программа обрабатывает результаты тестирования, рассчитывает средний
балл по учтённым попыткам и выводит студентов в порядке убывания
среднего балла.

Оценки с дополнительными знаками `+` и `-` учитываются при расчёте. Для
каждой записи рейтинга отображается средний балл и количество учтённых
попыток. Если у студента нет подходящих оценок, выводится отметка
`нет оценок`.

## 6. Обработка ошибок и отсутствие данных

При некорректном вводе программа выводит сообщение об ошибке и
возвращает пользователя в главное меню.

Если для выбранной группы отсутствуют подходящие файлы или записи,
программа сообщает об отсутствии данных для соответствующей операции.
Это не препятствует дальнейшему использованию меню.

Для корректной работы необходимо сохранять исходную структуру каталога
`labfiles-3-26` и не переименовывать файлы данных, используемые
приложением.

## 7. Завершение работы

Для завершения работы вернитесь в главное меню и введите:

``` text
0
```

Программа завершит работу без выполнения дополнительных операций.
