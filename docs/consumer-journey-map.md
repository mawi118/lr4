# Маршрут пользователя и примеры запуска

Примеры рассчитаны на синтетические данные из `tests/data/synthetic/labfiles-3-26`. Команды ниже выполняются из корня репозитория. Вывод сверён с текущим `scripts/lab4.sh`. На данных преподавателя значения могут отличаться.

## Подготовка

Скрипт ищет `labfiles-3-26` рядом с собой. Если этот каталог уже расположен в `scripts/`, обычный запуск выглядит так:

```bash
bash scripts/lab4.sh
```

Для повторения примеров на синтетических данных создайте временную копию скрипта и данных:

```bash
demo_dir=$(mktemp -d /tmp/lr4-demo.XXXXXX)
cp scripts/lab4.sh "$demo_dir/lab4.sh"
cp -a tests/data/synthetic/labfiles-3-26 "$demo_dir/labfiles-3-26"
bash "$demo_dir/lab4.sh"
```

После выхода из программы временную копию можно удалить командой `rm -r -- "$demo_dir"`. Исходные файлы репозитория при этом не меняются.

## Consumer journey map

| Этап | Цель пользователя | Действие | Что получает |
|---|---|---|---|
| Подготовка | Безопасно открыть программу | Запускает скрипт с копией данных | Главное меню с пунктами `1`–`5` и `0` |
| Анализ группы | Узнать лидеров | Выбирает посещаемость `1` или ответы `2` | Список лидеров и числовой результат |
| Проверка студента | Посмотреть подробности | Ищет ID через пункт `3`, выбирает запись | Заметку или полное досье по двум дисциплинам |
| Сравнение | Оценить успеваемость всей группы | Выбирает рейтинг `5` | Отсортированный список со средними баллами |
| Изменение данных | Удалить заметку или студента | Выбирает пункт `4`, режим и подтверждение | Отмена без изменений либо удаление на копии данных |
| Завершение | Закончить работу | Вводит `0` в главном меню | Программа завершается |

## Примеры ввода и результата

Каждая строка в блоках «Ввод» означает одно нажатие Enter. Последний `0` завершает программу. В выводе приведены только строки результата, без повторяющегося меню и приглашений к вводу.

### 1. Лидеры по посещаемости

Ввод: пункт `1`, период 2026–2026, обе дисциплины, группа `A-06-23`.

```text
1
2026
2026
3
A-06-23
0
```

Результат:

```text
Группа A-06-23, расчётный год 2026. Посещаемость по выбранным предметам:
IvanovII — 4/6 (66.66%)
PetrovPA — 4/6 (66.66%)
SidorovSS — 4/6 (66.66%)
```

### 2. Максимум правильных ответов

Ввод: пункт `2`, группа `A-06-23`, обе дисциплины.

```text
2
A-06-23
3
0
```

Результат:

```text
Максимум правильных ответов: 12
Студенты:
 - IvanovII
 - PetrovPA
 - SidorovSS
```

### 3. Полное досье студента

Ввод: пункт `3`, ID `IvanovII`, запись `1` из двух найденных групп, режим `2`.

```text
3
IvanovII
1
2
0
```

Фрагмент результата:

```text
Найденные студенты:
1) IvanovII — A-06-23
2) IvanovII — A-06-24
Студент: IvanovII | группа: A-06-23
Предмет: Цирковое_Дело | посещаемость: 3/4 (75.00%) | правильные ответы: 8 | попытки: 2 | средний балл: 4.12
Предмет: Пересдачеведение | посещаемость: 1/2 (50.00%) | правильные ответы: 4 | попытки: 1 | средний балл: 3.25
Заметки преподавателя:
Заметка Иванова.
```

### 4. Рейтинг группы

Ввод: пункт `5`, группа `A-06-23`, обе дисциплины.

```text
5
A-06-23
3
0
```

Фрагмент результата:

```text
Рейтинг группы A-06-23 (средний балл по всем попыткам):
 1. SmirnovBB              4.50 (2 попыток)
 2. PetrovPA               4.00 (2 попыток)
 3. IvanovII               3.83 (3 попыток)
 6. EmptyEE                нет оценок
```

### 5. Отмена удаления

Ввод: пункт `4`, студент `SmirnovAA`, запись `1`, режим полного удаления `2`, ответ `2` на подтверждение.

```text
4
SmirnovAA
1
2
2
0
```

Результат: `Отменено.` Файлы остаются прежними.

### 6. Удаление заметки на копии данных

Этот пример выполняйте только после запуска временной копии из раздела «Подготовка». Ввод: пункт `4`, студент `SmirnovAA`, запись `1`, режим `1`, подтверждение `1`. Затем пункт `3` проверяет, что студент остался, а заметка удалена.

```text
4
SmirnovAA
1
1
1
3
SmirnovAA
1
1
0
```

Результат удаления: `Удаление выполнено.` При последующем просмотре: `Студент: SmirnovAA | группа: A-06-23` и `Заметки отсутствуют.`

Для работы с собственной ФС разместите её как `labfiles-3-26` рядом с `lab4.sh`. Перед подтверждённым удалением сделайте копию данных.
