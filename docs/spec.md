# Спецификация v2: анализ файловой системы преподавателя

Ответственный: аналитик. Документ описывает F1-F4 из `docs/plan.md` и поведение `scripts/lab4.sh`. Спорные правила приняты по текущей версии скрипта: SHA-256 `56780f8781e4444174bdd5d541a17db749f9a30e521af13066f6742f245c14e9`.

## 1. Назначение и архитектура

Программа работает в терминале Linux с данными лабораторной работы №3. F1 определяет лидеров по посещаемости, F2 по правильным ответам, F3 показывает и удаляет досье, F4 строит рейтинг по оценкам.

Точка входа одна: `scripts/lab4.sh`. Функция `main` проверяет каталоги данных и показывает меню. Общие функции проверяют ввод и читают файлы; функции F1-F4 считают и выводят результаты. Отдельной базы данных нет. Для запуска нужны Bash и стандартные команды Linux, в том числе `grep`, `sed`, `sort` и `mv`.

## 2. Расположение и формат данных

Каталог `labfiles-3-26` должен находиться рядом со скриптом. В этом репозитории ожидаемый путь: `scripts/labfiles-3-26`. Текущая директория терминала на поиск данных не влияет.

```text
scripts/
├── lab4.sh
└── labfiles-3-26/
    ├── students/
    │   ├── groups/<группа>
    │   └── general/notes/*Names.log
    ├── Цирковое_Дело/
    │   ├── <группа>-attendance
    │   └── tests/TEST-*
    └── Пересдачеведение/
        ├── <группа>-attendance
        └── tests/TEST-*
```

| Данные | Формат |
|---|---|
| Группа | Файл `students/groups/<группа>`, один ID студента в строке. Имя группы: латинские буквы, дефис, две цифры, дефис, две цифры. Пример: `A-06-23`. |
| Посещаемость | Строка `<ID> <последовательность 0 и 1>`. `1` означает посещение. Строки с другими символами в последовательности пропускаются. |
| Тест | Строка `<группа>;<ID>;<дата>;<число правильных ответов>;<оценка>` в файле `TEST-*`. Число ответов состоит из цифр. Дата не участвует в расчётах. |
| Заметка | В файле `*Names.log`: строка-разделитель из `=` и возможных пробелов, затем ID, затем одна строка текста. Следующая строка без разделителя не входит в заметку. |

Исходной ФС преподавателя в репозитории нет. Совместимость с ней нужно проверить на копии; синтетические данные лежат в `tests/data/synthetic/labfiles-3-26`.

## 3. Терминальный интерфейс

Запуск из корня репозитория: `bash scripts/lab4.sh`. Ключей командной строки и переменной для выбора каталога данных нет. Меню и результаты выводятся в stdout, сообщения `Ошибка: ...` в stderr. После операции меню показывается снова. Пункт `0` завершает программу.

```text
1. Лучшая посещаемость за период
2. Максимум правильных ответов
3. Найти досье
4. Удалить досье
5. Рейтинг успеваемости
0. Выход
```

В F1, F2 и F4 выбор дисциплины одинаковый: `1` означает Цирковое дело, `2` Пересдачеведение, `3` обе дисциплины. Неверное значение вызывает ошибку и возврат в главное меню. Полное досье F3 всегда охватывает обе дисциплины.

## 4. Функциональные требования

### F1. Лучшая посещаемость

1. Пользователь вводит начальный год, конечный год, дисциплину и группу в этом порядке. Годы должны быть четырёхзначными, от 2000 до 2099 включительно; начальный год не больше конечного. Группа должна иметь файл списка.
2. Расчётный год группы равен `2000 + последние две цифры имени группы + 3`. Если он не входит в заданный период включительно, выводится сообщение об отсутствии занятий. Отдельные даты занятий в файлах посещаемости не указаны и не проверяются.
3. Для каждого студента из списка группы программа суммирует `1` и длины допустимых строк посещаемости по выбранным дисциплинам. Студенты без таких строк не участвуют в сравнении.
4. Сравнивается доля `посещено / всего`, а не абсолютное число посещений. Выводятся все студенты с максимальной долей в порядке списка группы: `<ID> — <посещено>/<всего> (<процент>%)`. Процент показывается с двумя знаками после точки без округления вверх.
5. Если ни у кого нет допустимых данных, выводится `Нет данных посещаемости.`

### F2. Максимум правильных ответов

1. Пользователь вводит группу, затем дисциплину. Программа читает все `TEST-*` выбранных дисциплин и отбирает строки по группе и ID из её списка.
2. Число правильных ответов суммируется по всем подходящим попыткам. Строка с нечисловым количеством пропускается. Если количество корректно, но оценка неверна, ответы входят в сумму, а попытка не входит в подсчёт среднего балла.
3. Для участия в выборе лидера студент должен иметь хотя бы одну попытку с допустимой оценкой. Допустимы оценки от `2` до `5`, без знака или со знаком `+`, `++`, `-`, `--`.
4. При равенстве максимума выводятся все лидеры в порядке списка группы. Формат: `Максимум правильных ответов: <число>`, затем `Студенты:` и строки ` - <ID>`.
5. Если подходящих студентов нет, выводится `Результаты тестирования отсутствуют.` Ноль правильных ответов допустим и может быть максимумом.

### F3. Поиск, просмотр и удаление досье

1. Пункты `3` и `4` запрашивают фамилию или полный ID латинскими буквами без пробелов. Поиск не зависит от регистра и сопоставляет ввод с началом ID. Найденные записи показываются с номерами, ID и группой. Пользователь выбирает номер; это позволяет различить однофамильцев и одинаковые ID в разных группах.
2. В пункте `3` режим `1` показывает строку `Студент: <ID> | группа: <группа>` и блок `Заметки преподавателя:`. Режим `2` дополнительно показывает по каждой дисциплине строку с посещаемостью `<посещено>/<всего>`, процентом, правильными ответами, числом попыток и средним баллом. При отсутствии оценок вместо среднего выводится `нет данных`; при отсутствии заметки выводится `Заметки отсутствуют.`
3. Заметка содержит одну строку текста после ID. Лишнюю строку без нового разделителя просмотр не показывает, а удаление заметки оставляет её в файле. Это принятое правило текущего формата данных.
4. В пункте `4` режим `1` удаляет только заметку выбранного ID. Режим `2` удаляет его из списка выбранной группы, файлов посещаемости и всех `TEST-*` обеих дисциплин, а также удаляет заметку. Данные других групп и студентов сохраняются.
5. Если тот же ID есть в другой группе, общая заметка сохраняется в обоих режимах удаления. Скрипт сообщает об этом. Записи выбранной группы в режиме `2` всё равно удаляются.
6. Перед изменением данных скрипт запрашивает подтверждение. Только ответ `1` выполняет удаление; любой другой ответ выводит `Отменено.` и оставляет данные без изменений. После успешного действия выводится `Удаление выполнено.`

### F4. Рейтинг успеваемости

1. Пользователь вводит группу и дисциплину. В рейтинг попадают все ID из списка группы, в том числе без оценок.
2. Средний балл считается по всем попыткам выбранных дисциплин, у которых корректны и число ответов, и оценка. Знаки меняют балл: `+` на `+0.25`, `++` на `+0.50`, `-` на `-0.25`, `--` на `-0.50`. Например, `4+` даёт `4.25`.
3. Список упорядочен по убыванию среднего балла, при равенстве по ID. Студенты без допустимых оценок стоят в конце с пометкой `нет оценок`.
4. Вывод начинается со строки `Рейтинг группы <группа> (средний балл по всем попыткам):`. Каждая следующая строка содержит порядковый номер, ID и средний балл с двумя знаками после точки и числом попыток. Дробная часть выводится без округления вверх. Для пустой группы строк студентов нет.

## 5. Ошибки и сохранность данных

- Если при запуске нет `students/groups` или `students/general/notes`, программа сообщает путь к ФС и завершается до показа меню с кодом `1`. Наличие остальных файлов заранее не проверяется.
- Неверный период, группа, номер найденного студента или режим F3 вызывают сообщение об ошибке. После него главное меню появляется снова. При выборе `0` последующий код завершения может быть `0`.
- Отсутствующие файлы посещаемости и `TEST-*` не прерывают работу. F1 и F2 выводят сообщения об отсутствии данных; F4 показывает студентов без оценок.
- F1, F2 и просмотр F3 не меняют исходные данные. Подтверждённое удаление F3 переписывает файлы; проверять его следует на копии ФС. При ошибке записи автоматического отката нет.
- F4 создаёт временный файл `.ranking.*` рядом со скриптом и удаляет его после штатного вывода. Для F4 каталог скрипта должен быть доступен на запись.

## 6. Сценарии приёмки

| Сценарий | Проверяемый результат |
|---|---|
| F1: период включает расчётный год, у двух студентов равная доля | Оба показаны как лидеры, порядок совпадает со списком группы. |
| F1: период не включает расчётный год | Показано отсутствие занятий, файлы не меняются. |
| F2: несколько файлов `TEST-*`, равный максимум | Ответы суммируются по попыткам, показаны все лидеры. |
| F2: правильные ответы с неверной оценкой | Ответы входят в сумму; попытка не повышает число оценок. |
| F3: несколько однофамильцев | Пользователь видит отдельные записи с группами и выбирает нужную. |
| F3: отмена удаления | Выводится `Отменено.`, файлы не меняются. |
| F3: удаление только заметки | Запись заметки исчезает; студент остаётся в группе, посещаемости и тестах. |
| F3: полное удаление | Студент исчезает из выбранной группы, посещаемости и тестов обеих дисциплин; сведения остальных студентов доступны. |
| F3: подтверждённое удаление, ID есть и в другой группе | Данные выбранной группы удалены, общая заметка и данные другой группы сохранены. |
| F4: оценки со знаками и студент без оценок | Средние рассчитаны по допустимым попыткам; студент без оценок расположен в конце. |
| F4: пустая группа | Выведен заголовок рейтинга без строк студентов. |

Подробные тест-кейсы и синтетическая ФС находятся в `tests/`. Проверка на исходной ФС преподавателя остаётся отдельным этапом после получения её копии.
