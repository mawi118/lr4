# Спецификация v2: F1-F4

Ответственный: аналитик. Эта версия описывает посещаемость (F1), правильные ответы (F2), досье (F3) и рейтинг (F4).

Основа: `docs/plan.md` и решение принять поведение `scripts/lab4.sh` для спорных случаев. Редакция скрипта: SHA-256 `56780f8781e4444174bdd5d541a17db749f9a30e521af13066f6742f245c14e9`.

## 1. Данные

Скрипт ищет каталог `labfiles-3-26` рядом с собой. При текущем расположении скрипта это `scripts/labfiles-3-26`. Данные из ЛР 3 пока не добавлены в этот репозиторий, поэтому структура ниже взята из кода и требует проверки на реальной копии.

```text
scripts/
├── lab4.sh
└── labfiles-3-26/
    ├── students/
    │   ├── groups/<группа>
    │   └── general/notes/
    ├── Цирковое_Дело/
    │   ├── <группа>-attendance
    │   └── tests/TEST-*
    └── Пересдачеведение/
        ├── <группа>-attendance
        └── tests/TEST-*
```

- Файл группы содержит один идентификатор студента в строке. Пример имени файла: `A-06-23`.
- Строка посещаемости содержит идентификатор, пробел и последовательность `0` и `1`. `1` означает посещение.
- Строка результата теста содержит поля `группа;студент;дата;правильные_ответы;оценка`.
- Заметка в `students/general/notes/*Names.log` состоит из строки-разделителя со знаками `=`, строки с ID студента и одной строки текста. Дополнительная строка не входит в заметку.
- F1, F2 и просмотр F3 только читают данные. Подтверждённое удаление F3 меняет файлы. F4 создаёт и удаляет временный файл рейтинга рядом со скриптом.

## 2. Архитектура

Одна точка входа: `scripts/lab4.sh`. `main` проверяет каталоги данных, показывает меню и вызывает F1-F4. `select_subject` выбирает один предмет или оба. F1 использует `attendance_one` и `attendance_all`; F2 и F4 используют `collect_tests`; F3 ищет студента, читает заметки и при подтверждении переписывает нужные файлы. Отдельной базы данных нет.

Для запуска нужны Bash и стандартные средства Linux. Ключи командной строки и переменная для выбора каталога данных не предусмотрены.

## 3. Интерфейс

Запуск: `bash scripts/lab4.sh` из корня репозитория. Путь к данным зависит от расположения скрипта, а не от текущей директории терминала.

Главное меню:

```text
1. Лучшая посещаемость за период
2. Максимум правильных ответов
3. Найти досье
4. Удалить досье
5. Рейтинг успеваемости
0. Выход
```

Ответы вводятся в терминале через stdin. Результаты и меню выводятся в stdout. Сообщения вида `Ошибка: ...` выводятся в stderr. После выполненной операции программа возвращается в меню. `0` завершает работу.

При выборе предмета: `1` - Цирковое дело, `2` - Пересдачеведение, `3` - оба предмета. Для группы используется формат из латинских букв и двух пар цифр через дефис, например `A-06-23`. Группа должна иметь файл в `students/groups/`.

## 4. Функции и формат результата

### F1. Лучшая посещаемость

Требование плана: по номеру группы показать студентов с наилучшей посещаемостью за заданный период.

Порядок ввода: начальный год, конечный год, предмет, группа. Допустимы годы от 2000 до 2099 включительно; начальный год не должен быть больше конечного.

Правило периода: год группы равен `2000 + последние две цифры группы + 3`. Он должен входить в диапазон включительно. Даты отдельных занятий не проверяются. Если год не входит в период, программа сообщает, что занятий нет. Иначе для каждого студента считает число `1` и общую длину строк посещаемости в выбранных предметах. Сравнивается доля посещений, а не абсолютное число. Выводятся все студенты с наибольшей долей в порядке списка группы. Для каждого показаны ID, посещённые и все занятия, процент с двумя знаками. Если данных нет, выводится `Нет данных посещаемости.`

Файл посещаемости без дат не позволяет выбрать отдельные занятия внутри года. Это ограничение принятого формата.

### F2. Максимум правильных ответов

Требование плана: по номеру группы показать студента с максимальным общим числом правильных ответов и само число.

Порядок ввода: группа, затем предмет. Пользователь может выбрать один предмет или оба. Программа читает `TEST-*` выбранных предметов, отбирает строки по группе и ID студента, суммирует правильные ответы по всем попыткам. При равном максимуме показывает всех студентов в порядке списка группы. Формат результата: `Максимум правильных ответов: <число>`, затем `Студенты:` и список ID. Если подходящих результатов нет, выводится `Результаты тестирования отсутствуют.`

Число ответов учитывается, если оно записано цифрами. Оценка для учёта попытки должна быть от `2` до `5`, со знаком `+`, `++`, `-` или `--` либо без знака. При неверной оценке корректное число ответов всё равно добавляется к сумме, но попытка не участвует в среднем балле. Студент без попыток с допустимой оценкой не участвует в выборе лидера.

### F3. Досье и удаление

Поиск принимает фамилию или полный ID латиницей без пробелов, без учёта регистра. Если найдено несколько записей, пользователь выбирает номер. Режим просмотра `1` показывает заметку; режим `2` показывает по обоим предметам посещаемость, правильные ответы, число попыток, средний балл и заметку. При отсутствии заметки выводится отдельное сообщение.

Удаление запускается из пункта `4`. Режим `1` удаляет только заметку, режим `2` удаляет запись из списка группы, посещаемости и тестов обоих предметов. Оба режима требуют подтверждения `1`; другой ответ отменяет действие. Если тот же ID есть в другой группе, общая заметка сохраняется, даже при выборе режима `1`. Файлы другой группы не меняются. Операцию нужно проводить на копии данных, если сохранность оригинала важна.

Для заметки используется ровно одна строка текста. При дополнительной строке просмотр показывает только первую, а удаление оставляет дополнительную строку в файле: она не относится к записи заметки.

### F4. Рейтинг успеваемости

Пользователь вводит группу и выбирает один предмет или оба. Средний балл считается по всем попыткам с допустимыми оценками. Знаки `+`, `++`, `-`, `--` меняют оценку на 0.25, 0.50, -0.25 и -0.50 соответственно. Список сортируется по убыванию среднего; при равенстве баллов - по ID. Студенты без оценок идут в конце с пометкой `нет оценок`. Выводятся средний балл с двумя знаками и число попыток. Временный файл `.ranking.*` удаляется после штатного вывода.

## 5. Пользовательские сценарии

1. Пользователь выбирает F1, вводит период, предмет и существующую группу. Программа показывает лидера или нескольких лидеров с долей посещения.
2. Пользователь выбирает F1 и период без расчётного года группы. Программа сообщает об отсутствии занятий за период.
3. Пользователь выбирает F2, вводит группу и предмет. Программа показывает максимальное число ответов и всех студентов с этим результатом.
4. Пользователь выбирает F3, находит студента, просматривает досье или удаляет выбранные сведения после подтверждения.
5. Пользователь выбирает F4 и получает рейтинг группы по среднему баллу.
6. Пользователь вводит неверный год, номер предмета или группу. Программа сообщает об ошибке и снова показывает меню.
7. Пользователь вводит `0` в главном меню. Программа завершает работу.

## 6. Ошибки и ограничения

- Если нет `students/groups` или `students/general/notes`, меню не открывается, ошибка выводится в stderr.
- Неверный период, предмет или группа вызывают сообщение об ошибке. После этого меню появляется снова. Код завершения всего процесса при такой ошибке может быть `0`, если пользователь затем выбрал выход.
- Отсутствующий файл посещаемости или `TEST-*` не останавливает программу. При отсутствии пригодных записей выводится сообщение об отсутствии данных.
- Удаление F3 и рейтинг F4 создают временные файлы только для обработки данных. После штатного завершения они не остаются.

## 7. Принятые правила для спорных случаев

Период F1 определяется расчётным годом группы; посещаемость сравнивается по доле, все лидеры выводятся. F2 считает все попытки выбранных предметов и выводит всех лидеров; корректные ответы учитываются даже при неверной оценке. Заметка F3 однострочная. Рейтинг F4 основан на среднем балле. Эти правила приняты для текущей версии решения.
