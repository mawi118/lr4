## Данные и способ проверки

Синтетическая ФС в `tests/data/synthetic/labfiles-3-26` дополнена однофамильцами, заметками, оценками с модификаторами и одинаковым ID в разных группах. В ней есть обе дисциплины, пустая группа, студент без оценок и несколько попыток в разных файлах TEST. Контрольные значения: три студента имеют по 4/6 посещений и по 12 правильных ответов; лидер рейтинга SmirnovBB имеет средний балл 4.50.

Команда: `bash tests/run-tests.sh`. Каждый кейс запускает копию скрипта и данных. Ввод передаётся через stdin; проверяются вывод, ошибки, код завершения и файлы. Удаление проверяется только на отдельной временной копии: отмена не должна менять файлы, подтверждение должно менять только нужные записи. Один запуск ограничен 10 секундами, временные каталоги очищаются. Подробности по каждому кейсу: `../tests/test-cases.md`.
