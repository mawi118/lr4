# Отчёт о тестировании F1-F4

Дата: 10.11.2026. Повторно проверен `scripts/lab4.sh` (SHA-256 `1c7d695f74734ed989edc3a9b4b93962ea7725ac356f1f66999d7799a418be4a`) в WSL Ubuntu, Bash. Исходный скрипт не изменялся.

## Данные и способ проверки

Синтетическая ФС в `tests/data/synthetic/labfiles-3-26` дополнена однофамильцами, заметками, оценками с модификаторами и одинаковым ID в разных группах. В ней есть обе дисциплины, пустая группа, студент без оценок и несколько попыток в разных файлах TEST. Контрольные значения: три студента имеют по 4/6 посещений и по 12 правильных ответов; лидер рейтинга SmirnovBB имеет средний балл 4.50.

Команда: `bash tests/run-tests.sh`. Каждый кейс запускает копию скрипта и данных. Ввод передаётся через stdin; проверяются вывод, ошибки, код завершения и файлы. Удаление проверяется только на отдельной временной копии: отмена не должна менять файлы, подтверждение должно менять только нужные записи. Один запуск ограничен 10 секундами, временные каталоги очищаются. Подробности по каждому кейсу: `../tests/test-cases.md`.

Синтаксис Bash корректен. F1, F2 и F4 прошли прежние проверки. Исправление BUG-01 подтверждено: `F3-13` теперь PASS, заметка при совпадающем ID сохранена. Но удаление заметки уникального студента портит другие файлы заметок. В `F3-11` после удаления недоступна заметка Петрова, в `F3-12` после полного удаления недоступна заметка второго Смирнова. Это новый BUG-02. Сценарий завершился с кодом 1 из-за двух проваленных проверок.

Открытые вопросы: F2 добавляет правильные ответы из записи с неверной оценкой, но не считает попытку (`F2-08`). Многострочные заметки показываются и удаляются не полностью (`F3-17`, `F3-18`), но их поддержка не оговорена. Эти три кейса отмечены `NOT_SPECIFIED`. Трактовку периода F1 тоже нужно согласовать с заказчиком.
